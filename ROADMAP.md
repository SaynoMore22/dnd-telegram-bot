# Планы

Текущее и следующее по этому боту. Не билд-документация, просто список задач с прикидкой объёма.

## Сделано

- Карточка класса вместо простыни текста: кнопки «Таблица умений» / «Умения по уровням» / «Подклассы», починены баги парсинга сайта (colspan/rowspan в таблицах, потеря умений из-за сломанной пагинации на next.dnd.su).
- Редакция 2014 (dnd.su) для заклинаний, предметов и черт — кнопка переключения версии на карточке, фолбэк на 2014, если в 2024 не нашлось.
- Категория «Черта» (feats) — раньше не поддерживалась вообще, теперь есть в обеих редакциях.
- Главное меню на кнопках (`/start`, `/menu`): разделы → (для больших разделов) буква → постраничный список → карточка.

## В очереди

### 1. Персонаж — хранилище листов персонажей игрока

Цель: не искать в тетрадке/PDF, а хранить лист(ы) персонажа прямо в боте и быстро править их по ходу партии (хиты, инвентарь, ячейки заклинаний и т.п.), не перезаполняя всё заново.

**Поля листа (по официальному листу персонажа редакции 2024)**

- Основное: имя, класс(ы) и уровень(-и), подкласс, предыстория, вид, мировоззрение, опыт
- Характеристики: Сила/Ловкость/Телосложение/Интеллект/Мудрость/Харизма — значение и модификатор
- Спасброски: какие тренированы
- Навыки (18 шт.): тренировка/экспертиза, привязка к характеристике
- Бонус мастерства, Пассивное Восприятие
- Класс доспеха, Инициатива, Скорость
- Хиты: максимум / текущие / временные, Кости хитов (всего/потрачено)
- Спасброски от смерти (успехи/провалы)
- Атаки: оружие/заклинание, бонус атаки, урон и тип
- Снаряжение + валюта (ММ/СМ/ЭМ/ЗМ/ПМ)
- Умения и черты (умения класса, черты, расовые способности) — можно ссылаться на уже собранную базу классов/черт
- Владения и языки
- Заклинания: заклинательная характеристика, Сл спасброска, бонус атаки, ячейки (макс/текущие по уровням), известные/подготовленные заклинания — можно ссылаться на уже собранную базу заклинаний (с учётом редакции)
- Внешность/предыстория: возраст, рост, вес, глаза, кожа, волосы; черты характера/идеалы/связи/слабости; заметки (свободный текст)

**Что часто меняется в партии (приоритет для быстрого редактирования)**

HP (текущие/временные), спасброски от смерти, состояния/истощение, ячейки заклинаний (потрачено/осталось), инвентарь (добавить/убрать/количество), валюта, опыт → уровень.

**Набросок реализации**

- Новая таблица(ы) в SQLite: `characters` (владелец = telegram user id, основные поля) + `character_items`/`character_spells` как отдельные таблицы (список переменной длины).
- Меню «Персонаж» рядом с текущим главным меню: список своих персонажей → карточка персонажа (сводка) → кнопки быстрых действий (±HP, ±деньги, добавить/убрать предмет, отметить использование ячейки заклинания) + «Открыть полный лист».
- Полный лист — как карточка класса: не одна простыня, а секции по кнопкам (Характеристики / Навыки / Атаки / Заклинания / Инвентарь / Заметки).
- Создание персонажа — пошаговый диалог (класс/вид/предыстория можно подтягивать из уже собранной базы, чтобы не вбивать текст вручную).

**Оценка объёма:** большая задача, сравнимая по объёму с уже сделанным dual-edition + меню. Стоит бить на этапы: (1) базовые хиты/инвентарь/заметки без полного листа, (2) характеристики/навыки/спасброски, (3) привязка заклинаний и умений к существующей базе, (4) полноценный лист с созданием персонажа мастером.
